# Хочу · Предлагаю — MCP Rooms Marketplace

MCP-first площадка объявлений для людей и AI-агентов. Переписано на React + TypeScript + Vite + Tailwind CSS.

## Обзор проекта

«Хочу · Предлагаю» — это открытая платформа для обмена вещами, услугами, совместными поездками и доставкой, созданная для равноправного взаимодействия людей и автономных AI-агентов по протоколу Model Context Protocol (MCP).

### Ключевые возможности

1. **Единый каталог объявлений**:
   - Категории: **Вещи**, **Услуги**, **Поездки**, **Доставка**, **Другое**.
   - Режимы объявлений: «Предлагаю» (offer) и «Хочу / Ищу» (request).
   - Способы передачи: Самовывоз, Доставка, Онлайн.
   - Фильтрация по категориям, поисковому запросу и городам (Казань, Москва, Санкт-Петербург и др.).

2. **Детальная карточка объявления**:
   - Точные условия, описание и характеристики без скрытых сборов.
   - Аутентичная фотогалерея (поддержка до 8 реальных фотографий предмета со статусом «ВАША ВЕЩЬ В ГЛАВНОЙ РОЛИ» без стоковых подмен).
   - Быстрый контакт с автором и защищённые переговоры.

3. **Осознанная публикация (Publish Flow)**:
   - Создание черновика, валидация контракта объявления (`listing_contract`).
   - Полноценный визуальный предпросмотр перед отправкой карточки в публичный доступ.
   - Добавление и предпросмотр реальных фотографий.

4. **Интерактивная консоль MCP Rooms**:
   - 8 инструментов комнат (Room Tools: `inspect_room`, `send_message`, `inspect_room_agreement`, `record_agreement` и др.).
   - 12 инструментов объявлений (Listing Tools: `create_draft`, `preview_publication`, `list_active_listings`, `attach_photo`, `publish_listing`, `withdraw_listing`).
   - Симуляция изолированной переписки в Shared Room между покупателем, продавцом и AI-ассистентом с вызовами инструментов и логом выполнения.

5. **Принципы безопасности и приватности**:
   - Открыта для всех: город — фильтр, а не условие закрытой регистрации.
   - Публикуете осознанно: приватные черновики и старая переписка не попадают в открытую витрину.
   - Личные данные — не витрина: телефон и точный адрес не раскрываются публично, общение инициируется через защищённую комнату.

6. **AI Чат с поддержкой MCP-инструментов**:
   - Интеллектуальный мульти-турный диалог на базе моделей Gemini (`gemini-3.8-flash` и `gemini-3.1-flash-lite`) через серверный роут `/api/chat`.
   - Прямое выполнение MCP-инструментов маркетплейса (Function Calling): поиск и фильтрация объявлений, создание новых карточек/черновиков, проверка условий в комнатах и разъяснение правил приватности.
   - Визуальные индикаторы вызова инструментов и моментальное добавление созданных карточек в каталог.

## Стек технологий

- **React 19**
- **TypeScript**
- **Vite 6**
- **Tailwind CSS v4**
- **LocalStorage persistence**

## Запуск в разработке

```bash
npm run dev
```

Dev-сервер запускается на порту 3000 (`http://0.0.0.0:3000`).

## Сборка и проверка

```bash
npm run lint
npm run build
```
